# GachaWork Next.js
Undian 9 nama dengan 1 pemenang, edit nama, shuffle, riwayat lokal, export Excel.

## Jalankan (Windows PowerShell)
```powershell
npm install
npm run dev
```
Buka http://localhost:3000

Buka folder proyek di VS Code. Nama dan riwayat disimpan di LocalStorage browser. Excel diekspor sebagai `hasil-gacha-9-nama.xlsx`.
